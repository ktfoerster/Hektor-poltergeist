## Follow-up implementation

The first Boolean runner forked a fresh one-shot solver for every candidate,
so CaDiCaL learning was discarded between calls. The follow-up uses a
persistent owned worker with 200,000-conflict checkpoint slices. It streams
new clauses after an invalid candidate and keeps learned clauses across normal
UNKNOWN slices, while retaining an independent parent wall bound. A full
target-0 branch-0 smoke test accumulated 550,009 conflicts over eleven slices
in the same worker and stopped cleanly at its 90-second parent bound. Fifteen
tests now pass, including worker clause propagation and branch coverage for
both target orbits.
